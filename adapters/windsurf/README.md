# Windsurf (Cascade) Integration Guide

To configure Windsurf to use the **Vibe Coding Playbook**:

```bash
# Copy .windsurfrules into your project root
cp /path/to/vibe-coding-playbook/adapters/windsurf/.windsurfrules /path/to/your-project/.windsurfrules
```

Windsurf Cascade will automatically ingest these rules when executing planning and implementation turns.
